# GeoCore

**A geotechnical engineering platform for soil testing, ASTM workflows, field data, and laboratory results.**

GeoCore is a web application built to help geotechnical engineers input, visualize, and interpret subsurface data — making borehole logs and soil test results easier to work with and share.

---

## Features

- **Borehole Log Visualization** — Input subsurface data and generate clear, readable borehole logs
- **Soil Test Management** — Organize and track laboratory and field test results in one place
- **ASTM Workflow Support** — Structured workflows aligned with standard geotechnical testing procedures
- **Field Data Entry** — Capture and store field investigation data directly through the app
- **Geotechnical Reports** — Transform raw subsurface data into accessible, interpretable reports
- **Mobile-Friendly** — Designed to work on desktop and mobile devices, including offline-capable PWA

## Background

GeoCore started as a personal tool — I needed a better way to visualize borehole data during a geotechnical project, and the existing options were either too expensive, too complex, or not built for field use. It grew into a full platform that I'm now using and continuing to develop.

The project sits at the intersection of civil engineering and software — an area I believe is critical for modernizing how geotechnical work is done, especially in regions where expensive desktop software isn't accessible.

## Getting Started (Development)

\`\`\`bash
git clone https://github.com/mohamedmahmoud95/GeoCore.git
cd GeoCore
npm install
npm run dev
\`\`\`

Requires a Firebase project. Copy `.env.example` to `.env` and fill in your Firebase config keys.
